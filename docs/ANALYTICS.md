# Аналитика без выдуманных данных

В этой адаптации реализован локальный импорт нормализованного CSV из Google, Яндекса или другого
проверенного источника. Исходную выгрузку храните отдельно; сначала приведите её к явной структуре:
`date,page,query,clicks,impressions`. Пустое значение означает неизвестность, не ноль.

```bash
python mad.py analytics-import --provider google --file real-metrics.csv
python mad.py analytics-report
```

Ключ записи: источник + дата + страница + запрос. Повторный импорт обновляет запись, а не удваивает её.
Разные провайдеры не смешиваются. Суммы отражают только переданные строки; полнота всех запросов и дней
не предполагается. При пропусках CTR не вычисляется. Отчёт не выдаёт общие показы за цитирования ИИ.

Прямые OAuth-коннекторы GSC/Yandex из Bamboo не перенесены в эту версию: нет проверенной авторизации
MAD-auto, и нет оснований обещать запуск соответствующих API. Это явно ограниченная часть адаптации,
а не имитация успешного подключения. Код не делает сетевых запросов и не расходует API-квоты.

До/после правки сравнивайте одну страницу и намерение, одинаковые периоды, источник и покрытие.
Не связывайте любое изменение CTR с эффектом статьи без учёта позиции, сезона и состава запросов.
Полезные цели: обращения с конкретной конфигурацией, переходы в соответствующую документацию,
уточнение совместимости перед заказом, снижение повторяющихся вопросов поддержки.
