# Контракты данных

JSON Schema описывает отдельные записи источника, утверждения, сигнала и пакет статьи.
В рабочем CLI нет зависимости jsonschema: обязательные поля, связи между файлами, ограничения
применимости и хеши проверяет mad/core.py. Схема сама не проверяет истинность, права и актуальность.
Проверка схемы внешним редактором не заменяет команду validate.
