# mad-plan

Прочитайте AGENTS.md, docs/RESEARCH-FIRST.md и docs/COMMUNITIES.md.
Начните с `sources` и `research-new`. Реально выполните поиск и чтение средствами среды,
зафиксируйте проблемы, попытки решения, альтернативы, исходы и даты. До текста обязательны
анализ рынка и проверка того, что MAD-auto действительно имеет подходящее решение.

Заполните research.json и заметки с SHA256, затем выполните:
```bash
python mad.py research-check <id>
python mad.py plan-build <id>
```

`topics` остаётся списком гипотез, а не разрешённым контент-планом. Из plan-build получаются
JSON и Markdown с источниками, пользой, ограничениями, приоритетом и действием new/update.
Без сравнимых измерений оставьте not_measured. Не увеличивайте число тем, если реальных находок нет.

Делегируйте анализ исследователю, аналитику и инженеру доступными средствами. Верните пути файлов,
реально выполненные проверки и not_checked. Недоступную соцсеть не считать прочитанной.
Не создавайте статьи и не утверждайте их от имени человека в обход плана.
