# Поиск и цитирование в системах ИИ

Цель — сделать полезный материал доступным для обхода, правильного понимания и ссылок.
Нельзя гарантировать индексацию, позицию или цитирование «всеми нейросетями». Обход сайта,
поисковый индекс, получение страницы по запросу, включение в ответ и обучение модели — разные процессы.

## Содержание

Один конкретный вопрос, самостоятельное объяснение механизма и проверяемые шаги. Сначала ответ,
затем условия применимости, подготовка, действия, ожидаемые признаки, ошибки и ограничения.
Это организация для читателя, не искусственная нарезка текста ради алгоритма. Называйте версии,
различайте документированное и испытанное, помещайте источник рядом с важным утверждением.
Не делайте страницы для каждой перестановки поисковых слов. Не имитируйте отзывы, форумные обсуждения,
статистику, авторский опыт, испытания или признание бренда сторонними экспертами.

## Техническая передача разработчику сайта

Публичный HTML с основным текстом без входа, корректный HTTP 200, внутренние ссылки и один canonical.
У новой площадки подтверждён раздел `/blog/`; не создавать второй журнал `/journal/`.
Предпросмотр всегда noindex. При реальном импорте в CMS проверяются robots/meta/X-Robots-Tag,
канонический адрес, ссылки изображений и sitemap; правила авторизации/корзины не меняются.
Доступность роботу подтверждают реальные логи/WAF и средства проверки поисковой системы, не наличие Allow.

Экспорт даёт TechArticle (подтип Article) и BreadcrumbList. Авторство и даты выводятся также в текст.
Для новой статьи datePublished остаётся незаданной до действительной публикации. У импортированной
старой статьи сохраняется исходная дата; dateModified — только реальное изменение материала.
Нельзя выдавать статью за товар и добавлять выдуманные Offer/Review/AggregateRating.
FAQ можно писать для читателя; не обещать специальный результат поиска только за разметку FAQ.

## Разные роботы — разные решения

OAI-SearchBot относится к поиску ChatGPT, GPTBot — к возможному использованию контента для обучения;
разрешение одному не требует разрешения другому. ChatGPT-User обслуживает пользовательские обращения,
это не тот же механизм поискового обхода. Политику обучения выбирает владелец отдельно.
Для Google, Bing/Copilot, Yandex, Perplexity и Anthropic перед изменением правил проверяется текущая
официальная документация конкретного сервиса. Не копируйте неизменяемый список адресов/IP из старой статьи.

`llms.txt` не включён как обязательная мера: Google прямо сообщает, что не использует этот файл
для поиска. Нельзя обещать, что специальный текстовый файл, скрытые ключи или манипулятивная разметка
обеспечат цитирование. Отдельная машиночитаемая выгрузка допустима для собственного инструмента,
но не должна расходиться с публичной страницей.

## Проверка результата

Храните дату, систему, точную формулировку запроса и обнаруженный URL. Один удачный ответ не означает
постоянного присутствия. Переходы из ИИ, поисковые показы, цитирования и обращения клиентов — разные метрики.
Проверяйте доступные на дату работы отчёты GSC/Yandex; не выводите долю ИИ из общей статистики.

Проверенные отправные официальные источники, 2026-10-05:

Эта версия не проверяла индивидуальные кабинеты и журналы роботов MAD-auto и не заявляет
фактическую индексацию сайта в перечисленных системах.
