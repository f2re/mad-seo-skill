# Примеры

`signals.template.json` — незаполненный шаблон, импорт как реального наблюдения блокируется.
`trend.template.json` — синтетические числа для проверки арифметики, не показатели MAD-auto.
`article-demo/` — черновик по открытой документации о разных концах COM-пары. Не испытание
оборудования и не разрешение на публикацию. Авторство, реальные снимки и человеческая приёмка не заполнены.

С версии 1.1.0 article-demo — архивный пример структуры. Он намеренно не содержит
фиктивного исследования рынка и не получает исключение из проверки. Для нового использования
соберите реальное исследование, plan-build и research-link; затем повторите validate.
