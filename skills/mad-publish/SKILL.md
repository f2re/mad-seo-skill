# mad-publish

Прочитайте AGENTS.md и docs/PUBLISHING.md. Перед экспортом проверяются актуальное исследование,
неизменённый контент-план, технические факты и человеческая рецензия на конкретный хеш.
Без исследования или после его устаревания/изменения прежнее утверждение не используется.

Только по явному поручению человека выполните status, approve и export --approved.
Это локальный пакет, не опубликованная статья. Не вызывайте непроверенный API сайта,
не меняйте robots, цены и медиахранилище. Не обходите приёмку другими инструментами.

Commit/push кода по поручению пользователя не разрешает публикацию контента.
Верните существующие пути файлов, реально выполненные проверки и нерешённые вопросы.
