# Проверка поставки 1.1.0

Дата: 2026-10-07. Рабочая среда: Python 3.13.13.

Выполнены: 103 автотеста (все успешны), согласованность 42 файлов адаптеров,
проверка JSON/локальных ссылок и базы знаний. Базовые 60 тестов сохранены;
добавлены 43 проверки обязательного исследования, его актуальности и связи со статьёй.

Проверены отказ new без исследования/плана, запрет экспорта старого задания без привязки,
изменённые доказательства/план, неизвестная дата события, архивный вопрос вместо свежего тренда,
честные blocked соцсетей, независимость российских/внешних источников, проверка решения MAD-auto,
перепечатки и пути заметок. Тестовые данные синтетические, не статистика рынка.

Проведена отдельная модельная рецензия кода. Исправлены два воспроизводимых замечания:
повторный учёт одного первоисточника на разных площадках и обход проверки символической ссылки
через родительский каталог. Добавлены регрессионные тесты.

17 источников и 18 отправных публикаций перенесены из предварительной подборки; реестр не выдаёт
их за просмотренные заново ролики или текущее рыночное исследование. Полный проход браузеров,
публикация статьи и кабинеты соцсетей не тестировались. Новое исследование выполняет агент
реальными доступными средствами; Python проверяет полноту и связи, но не удостоверяет истинность.

CI настроен на Python 3.10–3.13. Удалённый результат проверяется после push;
локальный успех сам по себе не означает успешный запуск GitHub Actions.
Исторические проверки 1.0.0 доступны в истории git и прежних запусках CI.
