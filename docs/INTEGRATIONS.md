# Среды ИИ

Канонические сценарии находятся в skills/, роли — в agents/. Скрипт
`python tools/sync_adapters.py` формирует файловые точки входа для Codex,
Claude Code и Antigravity. `--check` обнаруживает расхождения, не изменяя файлы.

Codex получает .agents/skills, конфигурации read-only проверяющих в .codex/agents
и их реестр в .codex/config.toml. Claude Code получает .claude/skills и .claude/agents;
проверяющим разрешены только чтение/поиск, а автоматический выбор сценария публикации отключён.
Antigravity получает .agents/skills, справочные описания ролей и правило чтения AGENTS.md.
Координатор — основной агент среды; он назначает восемь проверяющих по необходимости,
а не запускает девять одинаковых авторов.

Конкретный механизм делегирования зависит от установленной версии среды и её разрешений.
Эта поставка проверяет целостность и ссылки адаптеров, но не заявляет запуск Codex,
Claude Code или Antigravity в данной рабочей среде. Если версия не читает соответствующий
реестр автоматически, используйте канонический файл роли как явное задание доступному
субагенту. Отсутствие средства делегирования указывается в отчёте.

Подписки и модели не предоставляются. CLI не вызывает LLM, не включает автозапуск,
не меняет системные разрешения и не сохраняет ключи. Интернет-поиск выполняется
разрешёнными инструментами самой среды, а не скрытым сборщиком в Python.
