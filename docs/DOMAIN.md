# Предметная область и границы обещаний

MAD-auto выпускает устройства и программные модули для связи с ЭБУ, регистрации параметров,
отображения приборов и работы с контроллерами ШДК. Название OBD2 не означает совместимость с ELM327.

| Объект | Допустимая опора | Чего не следует обещать |
|---|---|---|
| WiFi OBD2 | Собственный пакетный обмен, WiFi-Bridge, K-Line/CAN | Любой автомобиль, любая программа, ELM327/J2534 |
| ECU Logger | Логи диагностических параметров на microSD; файловый менеджер | Любой параметр ЭБУ, восстановление удалённого лога, облако без отдельной проверки |
| Dashboard | Программный модуль, данные выбранного протокола | Наличие Boost во всех прошивках, собственный физический датчик давления |
| WiFi AFR | Интерфейс к контроллеру ШДК | Прямую замену контроллера голого датчика, одинаковую шкалу для всех топлив |
| DSG, инженерные платы, другие контроллеры | Отдельная подробная документация | Распиновку, адаптации и универсальную совместимость по карточке товара |

Источники: `knowledge/sources.json`. Обнаруженные противоречия: `knowledge/conflicts.json`.
База отражает чтение документации, а не испытание на автомобиле. Точные матрицы из изображений
не восстановлены. Для DSG и Wireless Lambda Controller паспорт тематики есть, но статьи с
техническими обещаниями заблокированы отсутствием подробной базы возможностей.

Различайте название продукта, аппаратную ревизию, версию встроенного ПО, программный модуль,
клиентское приложение, диагностический протокол и калибровку ЭБУ. «Поддерживается М73» не означает,
что любая прошивка М73 выдаёт одинаковые параметры. Информация о цене, комплектации, гарантии,
доставке и наличии требует отдельной актуальной проверки; в базе цены намеренно отсутствуют.
