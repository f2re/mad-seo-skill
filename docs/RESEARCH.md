# Поиск проблем и нишевых изменений

Начните с `python mad.py search-plan`. Это список задач для исследователя с веб-поиском,
не результаты поиска. Найдите первичную ветку обсуждения, прочитайте контекст до/после вопроса,
зафиксируйте попытку решения и фактический исход. Drive2, профильные форумы и открытые сообщества
используются для вопросов; технические возможности подтверждаются документацией производителя.
Закрытые группы и переписка — только с разрешением и предварительным обезличиванием.

Одна карточка наблюдения: `id`, `problem_id`, `url`, `occurred_at`, `observed_at`, `kind`,
`evidence`, `attempted_solution`, `independence_key`, `public_or_redacted`.
Дата события неизвестна — `null`. Не подставляйте дату чтения, индексации, sitemap или переноса статьи.
Повторы URL с UTM не создают новые сигналы. Перепечатки и ответы в одной исходной ветке объединяются
одним ключом независимости. Окончательную независимость проверяет исследователь, не алгоритм.

```bash
python mad.py signals-import --file observations.json
python mad.py topics --days 30
```

`documentation_hypothesis` — вопрос есть в документации, актуальный спрос ещё не измерен.
`observed_interest` — есть датированное первичное наблюдение за выбранный период. Это не доказанный рост.
Показатель приоритета — редакционная оценка: документированное решение, число независимых сигналов,
наличие существующей статьи. Это не частотность запросов, деньги или прогноз продаж.

Для вывода о росте нужны соседние одинаковые полные окна одного источника, единицы и охвата.
`trend-check` принимает такие измерения, но не собирает их. Порог базы 20 и изменение 25% —
редакционные предохранители, не статистический тест значимости. Нулевая/малая база, пропуски,
разные источники, пересекающиеся окна → недостаточно данных или несопоставимость.
Не заявляйте «тренд 2026», опираясь на старый форум или дату миграции.

Новая проблема добавляется в `knowledge/problems.json` только после чтения источников и связи
с реальной возможностью из `capabilities.json`. Затем запускается `knowledge-check`.
Отсутствие подтверждённого решения — тема для исследования или вопрос инженеру, не продающая статья.
