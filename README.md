# MAD-auto · редакционный конвейер

Адаптация [bamboo-seo-skill](https://github.com/f2re/bamboo-seo-skill) для статей MAD-auto.

Предметная область: WiFi OBD2, WiFi AFR, WiFi Dashboard, ECU Logger и контроллеры КПП.
Основа материала: реальная пользовательская проблема → подтверждённая возможность продукта → проверяемая инструкция.

Исходный конвейер закреплён на версии `93a7b5bc28f45405d3fcf1f68bd464c6e946bfc4`.
Адаптация и проверки добавляются отдельным коммитом. Публикация статей на рабочий сайт не выполняется без утверждения владельца.
